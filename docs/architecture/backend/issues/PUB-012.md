## Contexto

`PublicationBuildJob` e dos testes de integração/BDD antes que IMP e COMP estejam disponíveis

integration-contracts §4 scaffold note: quando os módulos irmãos estiverem disponíveis, os stubs
são substituídos pelos adapters reais via troca de provider (sem alterar domínio/aplicação).
