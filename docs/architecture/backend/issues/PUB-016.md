## Contexto

GAP identificado em M3: o api-contract atual expõe apenas contagens (`totalErros`/`totalAvisos`) nos
endpoints de status e histórico, mas o FE precisará eventualmente renderizar a lista detalhada de
mensagens (`{code, message, location}`) para a tela de erros críticos. Este issue adiciona
`GET /api/pub/projetos/{projetoId}/publicacoes/{publicacaoId}/validation-messages` que devolve os
registros `ValidationMessage` paginados. **Requer aprovação de contrato** antes da implementação
(a rota não existe no api-contract ainda — precisa ser ratificada com o time de FE antes do promote).
