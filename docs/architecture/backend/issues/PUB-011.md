# PUB-011 -- FileStoragePort adapter (disk POC): store, signUrl, readImage, delete

**Status:** INTACT -- gerado 2026-08-25
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/4 itens

## Contexto

Implementar o adapter de armazenamento de arquivo `DiskFileStorageAdapter` que implementa
`IFileStoragePort` para o POC: grava o `.epub` em disco (`PUB_STORAGE_ROOT / emp_<slug> / publicacoes / <id>.epub`),
lê imagens por `storageKey`, assina URL com TTL curto via HMAC (ou retorna URL local com token de
expiração) e deleta o arquivo na erasure. Em produção, o adapter seria substituído por S3 sem alterar
o domínio (ADR-003).

## Spec de referencia
- SPEC-06 (security — URL assinada TTL curto, chaves tenant-scoped)
- SPEC-10 (integrations §infra — FileStoragePort store, signUrl, delete)
