## Contexto

Implementar o job assíncrono in-process `PublicationBuildJob.run(publicacaoId, empresaContext)`:
(1) `gerando` → lê ContentTree via `ManuscriptContentPort` + composição via `CompositionReadPort`,
monta o pacote ePub 3 via `EpubBuilder`; (2) `validando` → chama `EpubValidationPort.validate`,
persiste `validation_message`, mapeia o veredito via `PublicationStatus.mapVerdictToStatus`;
(3) terminal → grava `.epub` via `FileStoragePort` (se `publicado`) ou registra `resumoErro`
(se `com_erros`), persiste o desfecho; (4) chama `ProjectStatusPort.advanceTo` exatamente uma vez;
(5) despacha evento de domínio `PublicationSucceeded`/`PublicationFailed` after commit (best-effort).
