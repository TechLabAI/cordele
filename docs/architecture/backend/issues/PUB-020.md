## Contexto

GAP identificado em M2/M3: um crash do processo durante o build (etapa `gerando`/`validando`) deixa
a linha `Publicacao` presa em estado não-terminal, bloqueando futuros exports do mesmo projeto pelo
índice parcial `uq_publicacao_projeto_inflight`. A reconciliação automática (timeout → `com_erros`)
é **assunção pós-POC** (doc 06). No MVP, o operador deve corrigir manualmente. Esta issue documenta
o gap, cria o runbook operacional e o script de reconciliação manual — **sem** timeout automático.
