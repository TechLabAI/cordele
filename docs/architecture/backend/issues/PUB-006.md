## Contexto

Implementar `GetPublicationStatsUseCase` que agrega ao vivo as linhas de `Publicacao` do projeto
para produzir os KPIs das telas T07/T08: `total`, `publicadas` (`status=publicado`),
`comAvisos` (subset `epubcheckStatus=avisos`), `comErros` (`status=com_erros`),
`emAndamento` (não-terminal), e os campos `ultimo*` do registro mais recente. Sem store de analytics
separado — projeção pura das mesmas linhas que dirigem o histórico (D-O).

- SPEC-11 (publication-kpis-read-model — agregações, semântica dos campos, D-O)
