## Contexto

Scaffold the NestJS module entry point for Publication. `PubModule` registers the controller,
all use case providers, port DI tokens, and the `EmpresaContext` middleware. `PubController`
wires **all 5 routes** under `/api/pub/projetos/{projetoId}/publicacoes` — `POST /`,
`GET /{id}/status`, `GET /`, `GET /{id}/download`, `GET /stats` — returning stub responses
so that `pnpm build` passes before P2 use cases are implemented.
