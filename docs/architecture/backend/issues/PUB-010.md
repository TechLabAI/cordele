## Contexto

Implementar o adapter `EpubcheckValidationAdapter` que implementa `IEpubValidationPort`:
escreve o Buffer do ePub em arquivo temporário, executa o JAR do epubcheck como child process
(`java -jar $EPUBCHECK_JAR_PATH --json <output> <epub>`), parseia o relatório JSON para
`ValidationReport`, e limpa o arquivo temporário. Se `EPUBCHECK_JAR_PATH` não estiver
configurado ou o processo falhar (JRE ausente, crash), retorna `com_erros` explicitamente —
**nunca** publica artefato não validado (ADR-003 promessa central).
