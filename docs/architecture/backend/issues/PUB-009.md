# PUB-009 -- EpubBuilder domain service: montagem OCF/ePub 3 determinística

**Status:** INTACT -- gerado 2026-08-25
**Maturidade:** 0 -- Inicial
**Done/Total:** 0/5 itens

## Contexto

Implementar `EpubBuilder` (domain service puro, sem dependências de infra): recebe
`ContentTree` (IMP), `MetadadosRead` (COMP) e `ConfiguracaoLayout` (COMP) e produz um
`Buffer` com o pacote OCF/ePub 3 pronto para validação. Monta OPF manifest + spine +
`nav.xhtml` + documentos XHTML de conteúdo + CSS derivado do layout honrado (SPEC-03 §2)
+ capa como `cover-image`. Imagens (`image.storageKey`) são lidas via `IFileStoragePort`
(injeção de dependência), não diretamente. Empacotamento ZIP com `mimetype` não comprimido
(OCF spec).

## Spec de referencia
- SPEC-03 (epub-assembly-and-validation — OPF, spine, nav, CSS, mapeamento de layout, determinismo)
- SPEC-02 (build-orchestration — EpubBuilder como passo 1 do job)
