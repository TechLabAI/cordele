# 04 — Frontend Architecture Direction — IMP (Importação)

## 1. Stack

- Angular **21**, Nx **22.x**, TypeScript **strict**.
- RxJS 7.8 **+ Signals** (Signals are the default state primitive; RxJS only where streams are
  intrinsic — e.g. upload progress events, polling backoff).
- Jest for unit tests, **Playwright** for e2e (`apps/imp-e2e`).
- Custom dark design system via CSS tokens (`theme.css`) + Tailwind utilities; no SCSS token layer.
- Package scope **`@cordele`**; module skeleton generated by the local Nx plugin
  `@cordele/internal:module`.

## 2. App Boundary

IMP is registered in the Shell (`cordele-web`) via `IMP_MODULE_DESCRIPTOR`. The lazy entry is
`imp.module.ts`, living in `libs/imp/shell-entry` with importPath `@cordele/imp` (ADR-006).
`apps/imp` is a thin host whose `app.routes.ts` only does
`loadChildren: () => import('@cordele/imp').then(m => m.ImpModule)`, serving as build/serve target
and e2e base.

## 5. Routing Strategy

- Shell → `@cordele/imp` via `loadChildren`.
- Sub-routes via `loadComponent`: `/upload` → `feature-upload`, `/revisao-de-estrutura` →
  `feature-review` (routes may be nested behind a project id in specs, e.g.
  `/projetos/:projetoId/importar`).
- Guards: `canActivate: [authGuard, empresaGuard, accessGuard('imp.import')]`.
- The 4-step top bar (Importar · Configurar · Visualizar · Exportar) is IMP-owned for steps 1–2
  boundaries and rendered from `libs/imp/navigation`.

## 6. State Strategy

- **Signals-first, no NgRx.** Each facade holds private `signal<T>` and exposes `.asReadonly()`:
  - `ImportFacade` — upload state machine (`idle|uploading|parsing|done|error`), progress, projetoId.
  - `ReviewFacade` — manuscript summary, chapter list, pending fragments, status.
- `computed()` for derived flags (`canSubmit`, pending count badges).
- No manual `BehaviorSubject`; RxJS streams are converted to signals (`toSignal`) at the facade edge.
- Optimistic updates only for `ignoreFragment` with documented rollback (see doc 05).

## 7. Module Contract Strategy (`imp.contract.ts`)

| Field | Value (draft) |
|---|---|
| `MODULE_KEY` | `'imp'` |
| menu label | `Importação` |
| icon | upload glyph (`upload_file`) |
| permissions | `imp.import`, `imp.review`, `imp.confirm` |
| feature flags | `imp.reimport` (defaultState: on), `imp.ignoreFragment` (on) |
| routes anchor | `IMP_ROUTES` (`/upload`, `/revisao-de-estrutura`) |
| entry point | `IMP_MODULE_DESCRIPTOR` (consumed by `module-descriptors.ts` in Shell) |
