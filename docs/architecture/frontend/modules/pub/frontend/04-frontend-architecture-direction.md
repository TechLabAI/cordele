# 04 — Frontend Architecture Direction — PUB (Publicação)

## 1. Stack

- Angular **21**, Nx **22.x**, TypeScript **strict**.
- RxJS 7.8 **+ Signals** (Signals are the default state primitive; RxJS only where streams are intrinsic
  — e.g. the **status poll** that watches a `pendente` `Publicacao` until a terminal verdict, or the
  authenticated download stream — converted to signals at the facade boundary).
- Jest for unit tests, **Playwright** for e2e (`apps/pub-e2e`).
- Custom dark design system via CSS tokens (`theme.css`) + Tailwind utilities; no SCSS token layer.
  The **semantic result banners** (success / warning / error) and the epubcheck warning list map to
  design tokens (`--color-brand`, success greens, `--color-warning-ink`, `--color-error`).
- Package scope **`@cordele`**; module skeleton generated by the local Nx plugin
  `@cordele/internal:module`.

## 2. App Boundary

PUB is registered in the Shell (`cordele-web`) via `PUB_MODULE_DESCRIPTOR`. The lazy entry is
`pub.module.ts`, living in `libs/pub/shell-entry` with importPath `@cordele/pub` (ADR-006).
`apps/pub` is a thin host whose `app.routes.ts` only does
`loadChildren: () => import('@cordele/pub').then(m => m.PubModule)`, serving as build/serve target and
e2e base. PUB is **not** a landing module — it is entered from COMP's T06 "Exportar" (a project in
`em_composicao`) or from PROJ / T08 for a project that already has publications.

## 5. Routing Strategy

- Shell → `@cordele/pub` via `loadChildren`; PUB is **not** a default child (entered on handoff).
- Sub-routes via `loadComponent`: `/exportacao-e-validacao` → `feature-export`,
  `/download-e-historico` → `feature-history`. Specs may nest both behind a project id (e.g.
  `/projetos/:projetoId/exportacao`, `/projetos/:projetoId/download`) so the publication is always scoped.
- Guards: `canActivate: [authGuard, empresaGuard, accessGuard('pub.export'), pubStatusGuard]`, where
  `pubStatusGuard` admits T07 only for `em_composicao` and T08 for a project with ≥1 `Publicacao`,
  redirecting otherwise (to PROJ / COMP).
- **Intra-PUB flow** (T07 "Baixar" → T08) is a straight navigation carrying `projetoId`; the "Ajustar
  layout / metadados" links leave PUB for COMP. Deep-linking directly to T08 for a project with no
  publications resolves to the empty state (or redirect — Specs).

## 6. State Strategy

- **Signals-first, no NgRx.** Each facade holds private `signal<T>` and exposes `.asReadonly()`:
  - `ExportFacade` — `ExportVM` (`phase`, `progresso`, `publicacao`); drives the `gerando → valido |
    erros` transition; `computed()` `podeBaixar`. Owns the **status poll** lifecycle (start on request,
    stop on terminal verdict or navigate-away).
  - `HistoryFacade` — `HistoryVM` (`projeto`, `meta`, `publicacoes`, `status`); `computed()` for
    "versão atual" (index 0) and each row's `podeBaixar`.
- `computed()` for derived values (`podeBaixar`, `versaoAtual`, human file size formatting).
- No manual `BehaviorSubject`; RxJS is confined to the edges (the status **poll** and the authenticated
  download stream) and converted to signals (`toSignal`) at the facade boundary.
- **No optimistic writes.** PUB's only write is `requestExport` (create a `Publicacao`); its result is
  awaited/polled, never assumed. The verdict and `arquivoUrl` are always the server's — there is
  nothing to roll back (ADR-PUB-001).

## 7. Module Contract Strategy (`pub.contract.ts`)

| Field | Value (draft) |
|---|---|
| `MODULE_KEY` | `'pub'` |
| menu label | `Publicação` |
| icon | export / publish glyph (`file_export` / `publish`) |
| permissions | `pub.view`, `pub.export`, `pub.download` |
| feature flags | `pub.rexport` (defaultState: on — allow re-export of a published project), `pub.pdfExport` (defaultState: **off** — PDF is out of MVP scope) |
| routes anchor | `PUB_ROUTES` (`/exportacao-e-validacao`, `/download-e-historico`) |
| landing | not a landing module (`isHome: false`); entered from COMP/PROJ |
| entry point | `PUB_MODULE_DESCRIPTOR` (consumed by `module-descriptors.ts` in Shell) |
