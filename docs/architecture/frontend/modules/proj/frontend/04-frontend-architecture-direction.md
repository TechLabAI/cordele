# 04 — Frontend Architecture Direction — PROJ (Projetos)

## 1. Stack

- Angular **21**, Nx **22.x**, TypeScript **strict**.
- RxJS 7.8 **+ Signals** (Signals are the default state primitive; RxJS only where streams are
  intrinsic — e.g. cancelling an in-flight list request on empresa switch).
- Jest for unit tests, **Playwright** for e2e (`apps/proj-e2e`).
- Custom dark design system via CSS tokens (`theme.css`) + Tailwind utilities; no SCSS token layer.
- Package scope **`@cordele`**; module skeleton generated by the local Nx plugin
  `@cordele/internal:module`.

## 2. App Boundary

PROJ is registered in the Shell (`cordele-web`) via `PROJ_MODULE_DESCRIPTOR`. The lazy entry is
`proj.module.ts`, living in `libs/proj/shell-entry` with importPath `@cordele/proj` (ADR-006).
`apps/proj` is a thin host whose `app.routes.ts` only does
`loadChildren: () => import('@cordele/proj').then(m => m.ProjModule)`, serving as build/serve target
and e2e base. PROJ is the **default landing module** after sign-in (the library is the app home).

## 5. Routing Strategy

- Shell → `@cordele/proj` via `loadChildren`; PROJ is the default child route (app home).
- Sub-routes via `loadComponent`: `/biblioteca-de-projetos` → `feature-library`,
  `/download-e-historico` → `feature-history` (Specs may nest history behind a project id, e.g.
  `/projetos/:projetoId/historico`).
- Guards: `canActivate: [authGuard, empresaGuard, accessGuard('proj.view')]`.
- **Stage-aware "Abrir"** is resolved in `libs/proj/navigation`, not hard-coded in the template:
  `rascunho → IMP`, `em_composicao → COMP`, `publicado|com_erros → history/PUB`. The prototype
  currently links "Abrir" straight to `/editor-de-layout-preview`; production replaces that with the
  resolver so no status dead-ends.

## 6. State Strategy

- **Signals-first, no NgRx.** Each facade holds private `signal<T>` and exposes `.asReadonly()`:
  - `LibraryFacade` — project list + `status` (`loading|ready|empty|error`), empresa-scoped.
  - `HistoryFacade` — project header + publication list + `status`.
- `computed()` for derived flags (`canDownload`, `isCurrent`, empty-vs-ready).
- No manual `BehaviorSubject`; RxJS streams (list request, empresa-switch cancellation) are
  converted to signals (`toSignal`) at the facade edge.
- **No optimistic writes** — PROJ is read-oriented in the MVP; the only mutation-like action
  (download) is a browser navigation, not a state change.

## 7. Module Contract Strategy (`proj.contract.ts`)

| Field | Value (draft) |
|---|---|

| menu label | `Projetos` |
